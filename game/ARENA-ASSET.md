# Warehouse Yard Arena

Source: https://shuriken.studio/models/scenery/warehouse-yard-arena
Provider: Shuriken Studio. This local prototype uses Matt's downloaded GLB.
Keep the standalone model out of a public source release. For release planning, verify the current terms and link to the creator instead: https://shuriken.studio/legal/models

This is a walkable map preview, not a paintball match. The Godot scene instances the original mesh at 45% scale. The warehouse roof hides when the player is inside, and the existing door interaction returns to town from the signed exit in the south yard.
